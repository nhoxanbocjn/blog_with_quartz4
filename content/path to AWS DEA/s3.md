-- 4 type encryption in S3
- Server Side 
	- SSE - S3: AWS Manage all
	- SSE - KMS: User manage key by AWS Key manage System 
	- SSE - C: User manage key outside AWS
	- DSSE-KMS is just "Dual-Layer Server Side Encryption based on KMS".**
- Client Side : Encrypt Data before sending to AWS
-- Access Point like Security Management in S3 Bucket instead of configure a complicated Bucket Policy
